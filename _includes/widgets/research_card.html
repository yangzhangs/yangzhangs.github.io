Research

Modern software development is accompanied by artifacts that flow through pipelines and are shaped by ecosystems. We study this continuum to make software engineering more intelligent, reliable, and sustainable.

Software Artifacts
软件工件
Dockerfiles, code examples, and issue reports — the artifacts developers produce. We characterize their quality and executability, and build intelligent techniques to generate and repair them.
DockerFill (TSE'25) · Model-card Code (ASE'26) · Issue Templating (SANER'25)
Software Pipelines
软件流水线
Container builds, CI/CD workflows, cloud-native architectures and deployment, and MLOps — the pipelines that build, deliver, and operate software. We diagnose faults, predict performance, and improve reliability and efficiency.
Docker Build Faults (FSE'25) · MLOps Problems (IST'25) · GitHub Actions (ICSE'24) · Docker Build Duration (ASE'22) · Containerized CD (FSE'18) · Microservices Q&A (SANER'22) Distinguished Paper Award
Software Ecosystems
软件生态
Dependencies, trust, and risks across open-source ecosystems. We mine ecosystem-scale data to understand package deprecation, supply-chain risk, and long-term sustainability.
Deprecated NPM Packages (ISSTA'26) · Credibility Risk (JOS'26)
